# Искусственный интеллект в домах социального обслуживания

## Коротко: пять ответов

**1. Для кого.** Для директоров, заместителей и методистов стационарных организаций социального обслуживания (ДСО / дома-интернаты). Материалы семинар-совещания «Пространство Новых Идей 2.0» (Санкт-Петербург, 25–27 августа 2026 года; Минтруд России · Комитет по социальной политике Санкт-Петербурга). Продолжение логики проекта «Не просто накормить»: ступень → замер → закрепление. Голос доклада — академический научный русский: точная терминология, связное рассуждение, ясные тезисы.

**2. Какую задачу закрывает.** Поддержку решений о *ответственных* пилотах ИИ: карта применений, принцип «человек в контуре», и честный ответ, **где ИИ не нужен**. Не закупка «под ключ», а язык, фильтры и формы, чтобы директор мог внедрить, отложить или отказаться.

**3. Что это за репозиторий.** Конвейер семинарского **доклада и презентации**: главы Markdown в `chapters/` собираются в HTML и PDF; слайды лежат в `presentation/`. Это методический пакет, а не программный продукт.

**4. Чем это не является.** Это **не** промышленный ИИ-ассистент, **не** RAG-чатбот, **не** юридическая или медицинская консультация и **не** инструкция внедрять что-либо без локального пилота, замера и юриста учреждения. Репозиторий не содержит приложения, которое «отвечает жителям» или принимает решения о людях.

**5. Как понять, что доклад «сработал».** Читатель отличает факт, интерпретацию, рекомендацию и иллюстративный расчёт по формулировке и сноске (ярлыки в текст не выносятся); может назвать первую задачу и первую точку отказа; приложения дают рабочие формы (приказ, регламент, согласия, паспорт пилота), которые юрист адаптирует под учреждение.

Все суммы, эффекты и графики в докладе — **иллюстративные порядки** для пересчёта на свои условия. Подтверждённых рядов по внедрениям именно в российских ДСО в открытом доступе нет; доклад это фиксирует как исходную точку, а не прячет.

## Недопустимое использование доклада

Доклад **нельзя** читать как:

- разрешение закупить и включить систему «как написано» без пилота, паспорта и критериев остановки;
- основание для решений о жителе, переводе, режиме, лекарствах, диете или ране «по выводу модели»;
- рекомендацию распознавания лиц / биометрии, американских счетов и направлений, робота-сиделки вместо персонала;
- юридическое заключение или клинический протокол — нормы и редакции сверяет юрист и врач учреждения по официальным текстам;
- описание работающего сервиса в этом репозитории: сервиса нет.

Подробнее: [docs/limitations.md](docs/limitations.md), [docs/ethics-and-safety.md](docs/ethics-and-safety.md).

## Как читать

Короткий гид для директора и для технического читателя: [docs/how-to-read.md](docs/how-to-read.md). Полный маршрут — раздел 2 доклада (`chapters/02_kak_chitat.md`).

- Полчаса: разделы 4 (карта А–Е и кандидаты Ж–Н), 16 (дорожная карта), 23–25 (где не нужен, ошибки, отказ).
- Два часа: плюс право (10, 17), персонал (19), данные (21).
- Полное чтение — тому, кто ведёт пилот: формы в приложениях 1–17.

## Данные и приватность

Доклад опирается на **открытые** источники (нормативные акты, рецензируемые статьи, отраслевые обзоры). В репозитории **нет персональных данных реальных проживающих**: в формах стоят плейсхолдеры (`[ФИО]`, `[телефон]`, код жителя без фамилии); учебные кейсы используют вымышленные ситуации. Сканирование дерева (главы, скрипты, собранный HTML/Markdown) не выявило списков жителей, карт, СНИЛС, реальных телефонов или адресов. Не вставляйте в репозиторий рабочие файлы учреждения.

## Структура доклада

1. **Основания для решений** (разделы 3–8): объективка, три класса ИИ, практики, карта задач, термины.
2. **Прикладные направления** (9–15): документы, правовая рамка, видеоаналитика, наблюдение, голос, обучение, аналитика — рабочая карта **А–Е**.
3. **Кандидаты Ж–Н** (раздел 4.2 и связанные места в 7, 16, 23): лекарственная логистика, расписание смен, реминисценция и персональная музыка, дайджесты семьям, подсветка пробелов в журналах, питание и кухня, целостность кожи (пролежни и раздражение от влаги). Это расширения, не «вторая карта» и не приглашение купить американскую платформу счетов.
4. **Внедрение** (16–22): дорожная карта на 12 месяцев, правовой контур, жители и семьи, персонал, этика, безопасность данных, экономика.
5. **Честные ограничения** (23–25): где ИИ не нужен, типовые ошибки, критерии отказа и остановки.
6. **Кейсы и приложения 1–17**: приказы, регламенты, согласия, паспорта пилота и показателя, журналы, сценарии тренажёра.

## Сборка

Скрипты считают корнем каталог репозитория (`chapters/`, `output/`). Если существует старый путь агента `/mnt/agents/output/seminar_ai_2026` с папкой `chapters/`, он берётся как раньше. Переопределение: переменная `SEMINAR_BASE`.

```bash
export LANG=C.UTF-8
python3 scripts/build.py          # chapters/ → output/_report_full.md
python3 scripts/build_color.py    # → output/_report_color.html
# PDF (Chrome; в среде агента сработал так):
google-chrome --headless --disable-gpu --no-sandbox --no-pdf-header-footer \
  --user-data-dir=/tmp/chrome-pdf --virtual-time-budget=8000 \
  --print-to-pdf=output/Искусственный_интеллект_в_домах_соцобслуживания_доклад.pdf \
  file://$PWD/output/_report_color.html
python3 scripts/toc_pages.py      # номера страниц оглавления из PDF
python3 scripts/build_color.py    # второй проход HTML с номерами
# затем ещё раз Chrome — как выше
```

Нужны Python 3, **pandoc**, (для второго прохода оглавления) пакет `pypdf` и шрифты, на которые ссылается `scripts/build_color.py`: Noto Serif, Noto Serif Display (`/usr/share/fonts/truetype/noto/`) и Inter (`/usr/share/fonts/truetype/macos/`). Без них Chrome молча подставит другие шрифты, и вёрстка и число страниц поплывут: проверяйте `pdffonts` на готовом PDF. Промежуточные `_report_full.md`, `_report_color.html` и `toc_pages_color.json` пишет конвейер в `output/` **локально** и в git не входят. Для чтения без сборки берите PDF. После сборки запустите `python3 scripts/check_report.py --pdf output/Искусственный_интеллект_в_домах_соцобслуживания_доклад.pdf`: проверка сверяет сноски со списком источников, отсылки к разделам и приложениям, шрифты и текстовый слой PDF; та же проверка идёт в GitHub Actions на каждый pull request. Журнальные номера страниц в оглавлении считаются вторым проходом после PDF (`scripts/toc_pages.py` → `toc_pages_color.json`). Пока PDF не пересобрали, он может отставать от `chapters/` — это ожидаемо, см. [docs/limitations.md](docs/limitations.md).
