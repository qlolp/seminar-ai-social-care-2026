# Искусственный интеллект в домах социального обслуживания

Проект доклада и презентации для межрегионального методического семинар-совещания «Пространство Новых Идей 2.0» (Санкт-Петербург, 25–27 августа 2026 года, Минтруд России · Комитет по социальной политике Санкт-Петербурга).

Продолжение проекта «Не просто накормить» (вариативное питание в стационарных организациях): та же логика «ступень → замер → закрепление» и та же система маркировки (факт / интерпретация / рекомендация / иллюстративный расчёт).

## Состав

- **Доклад** — 109 страниц, 25 разделов в пяти частях, заключение, ответы на частые вопросы, 14 учебных кейсов, 17 приложений с формами документов, 11 инфографических листов, список источников:
  - `output/Искусственный_интеллект_в_домах_соцобслуживания_доклад.pdf` — готовая журнальная версия (A4, цветная)
- **Презентация** — 30 слайдов (формат .pptd, открывается в редакторе Kimi): `presentation/презентация_ии.pptd`
- **Исходники**: `chapters/` — разделы в Markdown; `scripts/` — конвейер сборки (build.py → build_color.py → Paged.js PDF)

## Структура доклада

1. Основания для решений (разделы 3–8): объективка, три класса ИИ, практики, карта задач, термины
2. Шесть прикладных направлений (9–15): документы, правовая рамка, видеоаналитика, наблюдение, голосовые помощники, обучение, аналитика
3. Внедрение (16–22): дорожная карта на 12 месяцев, правовой контур, жители и семьи, персонал, этика, безопасность данных, экономика
4. Честные ограничения (23–25): где ИИ не нужен, типовые ошибки, критерии отказа
5. Учебные кейсы и приложения 1–17 (приказы, регламенты, формы согласий, паспорта пилота и показателя, журналы, сценарии тренажёра)

## Сборка

```bash
export LANG=C.UTF-8
python3 scripts/build.py          # chapters/ → output/_report_full.md
python3 scripts/build_color.py    # → output/_report_color.html (двухпроходное оглавление: toc_pages_color.json)
node /app/.agents/skills/pdf/scripts/html_to_pdf.js output/_report_color.html -o output/доклад.pdf
```

Все суммы и эффекты в докладе — иллюстративные порядки для пересчёта на свои условия; подтверждённых данных по внедрениям именно в домах социального обслуживания в открытом доступе нет, и доклад честно фиксирует это как исходную точку.
