# Как читать этот пакет

Короткий гид поверх раздела 2 доклада (`chapters/02_kak_chitat.md`). Сам доклад — для человека, который принимает решение, а не «разбирается в моделях».

## Два маршрута

**Руководитель / методист ДСО.** Читайте маркировку фраз, карту и ограничения — не список вендоров.

1. Раздел 4: карта **А–Е** и кандидаты **Ж–Н** (что можно обсуждать, что сознательно вынесено). Текст глав — живой русский того же регистра, что и слайды.
2. Раздел 16: порядок кварталов; кандидаты Ж–Н садятся на карту, а не вместо неё.
3. Разделы 23–25: где ИИ не нужен, семь «никогда», критерии отказа.
4. Приложения — формы, которые юрист и врач подставят под ваши реквизиты.

Полчаса: 4 + 16 + 23–25. Два часа: плюс 10, 17, 19, 21.

**Технический читатель** (ИТ учредителя, вендор, ревьюер репозитория). Это не кодовая база ассистента. `scripts/` только склеивают Markdown → HTML/PDF. Не ищите `src/`, RAG, ключи API и «прод». Имеет смысл смотреть: карту задач (7), правовой контур (17), безопасность (21), запретную зону (24), этот каталог `docs/`.

## Четыре статуса фразы

Как в докладе о вариативном питании:

| Маркер | Значение | Что с ним делать |
| --- | --- | --- |
| **Факт** | Проверяется по источнику | Можно цитировать; сверка — по сноске |
| **Интерпретация** | Вывод авторов из фактов | Спорить можно; это не «данные отрасли» |
| **Рекомендация** | Что советуем делать у себя | Не приказ и не норма; решение — за директором |
| **Иллюстративный расчёт** | Порядок величины | Пересчитать на свои ставки, койко-места, тарифы |

Если данных нет, в тексте так и написано. Обещание вендора без вашего замера — не факт.

## Что значат сноски

Верхние индексы (`<sup>1</sup>`, в Markdown — `¹` или `<sup>2</sup>`) отсылают к **списку источников** (`chapters/34_istochniki.md`): законы, статьи, обзоры. Номер в тексте ≠ номер статьи закона. Перед тем как переносить формулировку в приказ, сверьте **действующую редакцию** по официальному порталу: список мог устареть.

Коды вида `[S045]` — внутренние ярлыки курируемых публикаций, удобные при обновлении списка. Они не заменяют библиографическую запись.
