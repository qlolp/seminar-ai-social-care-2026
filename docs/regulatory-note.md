# Правовая рамка: российское право — основное

Этот файл **не** юридическая консультация и не выжимка иностранных актов. Нормы применяет юрист учреждения по официальным текстам.

**Основная рамка — российская.** Для пакета семинара это:

- **152-ФЗ** «О персональных данных» (в т. ч. ст. 16 — решения не оставлять только машине);
- **442-ФЗ** «Об основах социального обслуживания граждан в Российской Федерации»;
- локальные акты учреждения и договор с вендором.

Развёрнуто в докладе: раздел **10** (рамка и запретная зона) и раздел **17** (пошаговый контур: ответственный, реестр, Роскомнадзор, семь пунктов договора; 17.8 — ориентировка по документам ФСТЭК об ИИ на 01.09.2026, не новый закон для ДСО). Указатель в главы — [ethics-and-safety.md](ethics-and-safety.md).

**Зарубежные материалы** (европейский регламент о данных, британский закон об уходе, обзоры домов длительного ухода) в источниках и сравнительных абзацах — **только сравнение**. Они не заменяют 152-ФЗ / 442-ФЗ и не становятся вашей местной нормой. Не переносите формулировки иностранного акта в приказ российского ДСО.

Перед приказом сверьте **действующую редакцию** на официальном портале: список источников мог устареть.
