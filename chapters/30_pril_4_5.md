# Приложение 4. Библиотека проверенных запросов к модели

<div class="lead">

Здесь собраны десять промптов, то есть готовых запросов к модели, — шаблоны для повседневной работы с документами. Каждый запрос сначала опробуют на текстах учреждения и только потом вносят в библиотеку, указав дату проверки и имя проверившего. Все запросы построены по одной схеме: роль модели, задача, исходный материал, вид результата, ограничения.

</div>

**4.1. Сводка журнала смены.** «Ты — помощник руководителя социального учреждения. Изложи следующий текст в 10 строках: что произошло за смену, что сделано и что требует решения руководства. Не добавляй фактов, которых нет в тексте. Текст: [обезличенный текст]».

**4.2. Ответ на обращение гражданина.** «Подготовь заготовку официального ответа на обращение: подтверждение того, что обращение получено, с регистрационным номером; ответ по каждому пункту обращения; сроки исполнения; контакт для вопросов. Тон уважительный, без канцеляризмов. Обращение: [обезличенный текст]».

**4.3. План занятий.** «Составь план занятий отделения на неделю: 5 дней, по 2 занятия в день продолжительностью 30–40 минут. Учти, что среди проживающих есть люди с нарушениями слуха и зрения. Перечисли нужные материалы. Направления: лёгкая гимнастика, творчество, тренировка памяти и внимания, музыка».

**4.4. Разбор протокола.** «Выпиши из протокола совещания три списка: принятые решения; поручения с ответственными и сроками; нерешённые вопросы. Не придумывай ответственных, которых нет в тексте. Протокол: [текст]».

**4.5. Упрощение текста для семьи жителя.** «Перепиши следующий служебный текст так, чтобы он был понятен родственнику проживающего: сохрани все факты, убери канцеляризмы, уложись в 150 слов, пиши спокойно и уважительно. Текст: [обезличенный текст]».

**4.6. Проверка письма.** «Найди в письме канцеляризмы, длинные предложения (более 25 слов) и неясные места. Предложи правки списком: исходный фрагмент, исправленный вариант, причина правки. Письмо: [текст]».

**4.7. Заготовка отчёта учредителю.** «Составь структуру квартального отчёта учреждения социального обслуживания для учредителя: разделы, основные показатели в каждом разделе, места для таблиц и выводов. Сам отчёт не пиши — только структуру с пояснениями, что включить в каждый раздел».

**4.8. Сценарий беседы с новым сотрудником.** «Подготовь план первой беседы руководителя с новым сотрудником отделения: 10 вопросов и тем, порядок знакомства с регламентами, типичные ошибки новичков, к кому обращаться за помощью. Объём — одна страница».

**4.9. Сравнение вариантов.** «Сравни два варианта решения задачи [описание задачи] по стоимости, срокам, рискам, возможности отказаться от решения и влиянию на проживающих. Вариант 1: [описание]. Вариант 2: [описание]. Сведи сравнение в таблицу и напиши, каких данных не хватает, чтобы сделать выбор».

**4.10. Инструкция по одному действию.** «Напиши для сотрудника инструкцию из 5–7 шагов: [действие, например "как записать инцидент в журнал"]. Каждый шаг — одно действие, и начинается он с глагола. В конце добавь строку «Частые ошибки» и строку «Кому сообщить, если что-то пошло не так»».

*Правило библиотеки: если запрос дважды дал непригодный результат, его переписывают, а прежнюю версию хранят рядом вместе с причиной замены.*

# Приложение 5. Чек-лист договора с поставщиком и реестр систем

Юрист проверяет договор по этому чек-листу до подписания. Строки 1–7 обязательны: если поставщик отказывается принять хотя бы одну из них, это основание не заключать договор (раздел 17.5). Правовые требования к договору подробно изложены в разделе 17. Государственное учреждение, которое закупает по 44-ФЗ или 223-ФЗ, применяет чек-лист раньше: строки 1–7 вносят в техническое задание и проект контракта ещё до размещения извещения, потому что после торгов условия контракта, как правило, уже не меняются (раздел 17.5). Применимость конкретных норм проверяют юрист и контрактный управляющий.

## 5.1. Чек-лист договора (проверяет юрист до подписания)

| № | Пункт | Что должна содержать формулировка | Есть / нет |
| --- | --- | --- | --- |
| 1 | Данные принадлежат учреждению | Поставщик обрабатывает данные только по поручению учреждения; права на данные к нему не переходят | |
| 2 | Где хранятся данные | Серверы находятся на территории РФ; адреса и операторы названы | |
| 3 | Запрет обучать модели на данных учреждения | Данные учреждения не используются для обучения моделей поставщика без отдельного письменного согласия | |
| 4 | Удаление данных при расторжении | Срок и порядок уничтожения данных после окончания договора, акт об уничтожении | |
| 5 | Ответственность за утечку | Ответственность определена конкретно и не ограничена стоимостью договора | |
| 6 | Право на проверку | Учреждение вправе проверить, как хранятся и обрабатываются данные | |
| 7 | Условия выхода из договора | Выгрузка всех данных в открытом формате (CSV/PDF), срок выгрузки и её стоимость (ноль) | |
| 8 | Уровень обслуживания | Время реакции на инцидент, канал поддержки, часы работы | |
| 9 | Изменение тарифов | Уведомление за 60 дней; право расторгнуть договор без штрафа, если цена выросла | |

*Строки 1–7 обязательны: отказ поставщика принять любую из них — основание не заключать договор (раздел 17.5).*
