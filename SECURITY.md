# Безопасность

Этот репозиторий — **документация и конвейер вёрстки** семинарского доклада, не сетевой сервис и не обработчик персональных данных. Секретов, ключей API и рабочих баз учреждения здесь не ожидается.

Не коммитьте `.env`, выгрузки журналов, списки проживающих, согласия с реальными ФИО и договоры с печатями. Шаблоны в приложениях нарочно содержат плейсхолдеры.

Если всё же нашли учётные данные, токен или файл с персональными данными в истории git — напишите владельцу репозитория (на GitHub: Issues с пометкой, что не публикуете секрет в открытом тексте, либо личное сообщение владельцу). Это не программа вознаграждения за уязвимости: чинить здесь нечего, кроме утечки, которую нужно вычистить из истории.
